# 方块噩梦 (Blocky Horror)

一款基于 **Three.js + TypeScript** 的第一人称恐怖迷宫逃脱游戏。你在一座由云端关卡驱动、道具每局随机分布的豪宅中寻找钥匙并从大门逃脱，同时躲避会沿 A\* 路径追击你的幽灵。

![tech](https://img.shields.io/badge/Three.js-0.168-blue) ![tech](https://img.shields.io/badge/Vite-6-purple) ![tech](https://img.shields.io/badge/TypeScript-5.7-informational)

---

## ✨ 游戏特性

- 🏚️ **关卡驱动的豪宅生成** —— 房间矩形与手绘走廊由关卡配置决定（1~N 个房间，云端可改），重叠/贴边自动拼接成不规则大房间，孤岛房间自动补 L 形走廊防死局
- 🧱 **分区墙体材质** —— 房间墙 / 走廊墙 / 转角墙三套材质，拐角处多材质 BoxGeometry 实现视觉切换
- 👻 **幽灵 AI** —— `patrol ↔ chase` 状态机，Bresenham 栅格视线 + A\* 二叉小堆寻路；发现玩家后加速 1.5 倍追击，巡逻速度逐关可配（2.0~6.0 米/秒）
- 🔦 **手电筒系统** —— SpotLight 光锥，可切换开关，小地图上以扇形显示
- 🗝️ **交互系统** —— 钥匙、雷达、鞋子（拾取后移动加速 50%）、灯光开关、橱柜躲藏、出口门
- 🗺️ **实时小地图** —— M 键切换小/大尺寸，带雷达后可见幽灵位置；可按关卡整体关闭（此时雷达也不投放）
- 💓 **动态心跳** —— 按距离实时调整音量与频率
- 🎵 **程序化音效** —— 全部用 Web Audio API 合成，零音频资源
- 🌐 **中/英自动切换** —— 根据 `navigator.language` 自动选择
- ⚡ **零重载重开** —— 死亡/胜利后内存级重建地图，不刷新页面
- 🗺️ **云端可配置关卡** —— 选关卡片面板（地图缩略图）+ 顺序解锁，编辑器保存即全网生效，关卡可冻结停用
- 🎨 **像素风关卡编辑器** —— `/level` 路径，口令门禁；拖拽画房间/走廊、逐关配置灯光/视距/幽灵/小地图，界面与弹框与游戏同款风格

## 🎯 目标

1. 在豪宅中找到 **逃脱门钥匙**（金色方块）
2. 到达 **出口门** 安全逃脱
3. 全程躲避幽灵——被触碰即死亡

## 💡 玩法提示

- 灯光开关会切换环境光强度与雾距，影响视野；开灯后全图通视
- 橱柜可以躲藏；幽灵会在玩家进入隐藏后放弃追击
- 拾取雷达装置后，小地图上会显示幽灵位置
- 拾取鞋子后移动速度 ×1.5（步行 6、奔跑 9），高难度关卡的保命关键
- 幽灵看见你（20 米内、正面视野、无墙遮挡）会加速 1.5 倍追击——听到心跳加快就快跑或找柜子

## 🚀 快速开始

```bash
# 安装依赖
pnpm install

# 启动开发服务器（默认 http://localhost:5173）
pnpm dev

# 本地联调 Cloudflare Functions + KV（关卡云端 API + 编辑器，默认 http://localhost:8788）
pnpm dev:cf

# 构建生产版本到 dist/
pnpm build

# 预览生产构建
pnpm preview

# 类型检查（无产物输出，含 functions/ 子项目）
pnpm typecheck

# 运行单元测试（关卡 Schema / 进度 / 云端加载）
pnpm test

# 构建并部署到 Cloudflare Pages
pnpm run deploy
```

> 使用 `npm` / `yarn` 亦可，把 `pnpm` 替换即可。

## 🏗️ 核心架构

### 地图生成管线（`World.generateMansion`）

1. `100×100` 栅格全部置为墙（与小程序版关卡坐标系对齐）
2. 按当前关卡配置的 `rooms[]` 挖出房间（数量由关卡决定，重叠/贴边自动打通合并）
3. 按关卡配置的 `corridorRects[]` 挖出手绘走廊；与 1 号房不连通的孤岛房间自动补 L 形直廊兜底
4. 把每面墙分类为 **房间墙 / 走廊墙 / 转角墙**
5. 房间墙 / 走廊墙用 `InstancedMesh` 批量渲染
6. 转角墙用多材质 `BoxGeometry`，每面朝向不同区域时贴不同贴图
7. 房间轮转分配（不足时同房复用）**门 / 开关 / 钥匙 / 雷达 / 鞋子 / 橱柜**（关卡关闭小地图时不放雷达）
8. 门和开关必须"贴墙"，生成前会校验相邻格为墙体；橱柜避开玩家出生格

### 幽灵 AI（`Ghost.update`）

```
patrol ─── 看到玩家（×1.5 加速）──→ chase
   ↑                                │
   └────── 玩家躲藏 / 追丢 ──────────┘
```

- **发现条件**：未躲藏 + 20 米内 + 前方约 145° 视野锥 + 栅格视线无墙/高柜遮挡（四者同时满足）
- **视线**：Bresenham 栅格遍历，O(距离) 零分配
- **寻路**：A\* + 二叉小堆，500 ms 重规划一次
- **失败安全**：追击无法推进超过 30 秒，自动放弃转巡逻

### 速度体系（统一 ×1.5 链条）

| 对象 | 基础 | 加成 |
| ---- | ---- | ---- |
| 玩家 | 步行 4 米/秒 | Shift ×1.5 = 6；拾鞋再 ×1.5（步行 6 / 疾跑 9） |
| 幽灵 | 巡逻 2.0~6.0 逐关可配（默认 3） | 追击 ×1.5 = 3~9 |

### 碰撞模型

- 墙 / 地板 / 天花板：直接查栅格，邻 3×3 范围 AABB 检测
- 家具：`Set<string>("x,y,z")` 线性扫描（小集合即可）

## 🧩 关卡编辑器（/level）

线上访问 `https://<你的域名>/level`（本地 `pnpm dev` 后访问 `http://localhost:5173/level`）：

- **口令门禁**：进入即校验管理口令（服务端 `POST /api/levels` 预校验），通过后才可编辑；断网时可「离线进入」仅编辑本地草稿
- **绘制**：房间模式拖拽画房间（最小 6×6，可重叠/贴边拼大房间）；走廊模式拖 1 米宽直线走廊，自动按房间边裁剪；Ctrl+滚轮缩放、空格拖拽平移
- **逐关参数**：房间灯光、关灯房间亮度、关灯可视距离、显示小地图、出现幽灵、幽灵速度
- **关卡管理**：新增 / 删除 / 冻结（暂时停用，游戏跳过、顺位前移，可解冻）；至少保留一个启用中的关卡
- **保存**：「保存到云端」写入 KV，所有玩家刷新即玩到新关卡（边缘节点约 1 分钟同步）；导入/导出 JSON 与小程序版格式兼容
- **草稿保护**：编辑自动存本地草稿，与云端冲突时弹框二选一，绝不静默覆盖

界面与全部弹框均为游戏页同款像素风，布局自适应 1280×800 ~ 1920×1080 屏幕。

## 🌐 本地化

游戏根据浏览器语言自动选择中/英两套文案：

- `zh-*` → 中文
- 其他 → 英文

词典位于 `src/localization.ts`，添加新语言只需扩展 `translations` 映射。

项目已内置 `pnpm run deploy` 脚本（= `vite build` + `wrangler pages deploy dist`，
`wrangler` 已是 devDependency，无需额外安装）：

